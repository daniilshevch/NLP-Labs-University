# Лабораторна робота 3 — Класифікація текстів за допомогою embeddings

Практична робота з використанням word embeddings для класифікації текстів на прикладі відгуків IMDB.

## Мета

Перевірити, як попередньо навчені векторні представлення слів можуть перетворювати цілий документ на компактний числовий вектор і використовуватися як ознаки для класифікатора.

## Виконані етапи

- Завантажено 50 000 GloVe-векторів розмірності 200.
- Реалізовано токенізацію тексту за правилами spaCy з приведенням токенів до нижнього регістру.
- Враховано особливості токенізації embeddings, зокрема розбиття скорочень на окремі токени.
- Реалізовано метод **Bag-of-Embeddings**:
  - для кожного токена знайдено GloVe-вектор;
  - невідомі токени пропущено;
  - вектори відомих слів усереднено;
  - отримано фіксований вектор документа.
- Перевірено, що розмірність документа не залежить від кількості слів у ньому.
- Векторизовано навчальну та валідаційну частини датасету.
- Навчено логістичну регресію на ознаках Bag-of-Embeddings.
- Для порівняння побудовано baseline на TF-IDF bag-of-ngrams з логістичною регресією.
- Досліджено, як зміна розміру навчальної вибірки впливає на якість Bag-of-Embeddings і TF-IDF моделей.
- Розглянуто embeddings matrix розміру `|V| x d`, де `|V|` — розмір словника, а `d` — розмірність embedding.
- Реалізовано отримання embedding через:
  - множення one-hot вектора на embeddings matrix;
  - `torch.nn.Embedding`.
- Перевірено, що обидва способи повертають однаковий вектор слова.
