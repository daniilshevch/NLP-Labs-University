# Основи великих мовних моделей

Навчальний репозиторій з лабораторними роботами з курсу **«Основи великих мовних моделей»** у **Національному університеті «Львівська політехніка»**.

Дев'ять практичних робіт складаються в повний шлях NLP: від ручної токенізації та Bag-of-Words через n-грамні й нейромережеві мовні моделі, RNN і GPT-2 до fine-tuning трансформерів і застосунків на LLM. Більшість алгоритмів спершу реалізовано вручну на NumPy або PyTorch, а потім порівняно з готовими бібліотеками.

## Лабораторні роботи

### Лабораторна робота 1 — Класифікація текстів

У роботі реалізовано модель бінарної класифікації тональності відгуків на фільми на основі датасету IMDB.

Основні теми:

- завантаження та дослідження датасету IMDB;
- токенізація тексту за допомогою spaCy та регулярних виразів;
- стемінг і видалення стоп-слів;
- побудова словника токенів;
- one-hot представлення;
- Bag-of-Words;
- Bag-of-n-grams;
- TF-IDF;
- feature hashing;
- навчання логістичної регресії;
- оцінювання за метриками accuracy, precision, recall і F1-score;
- порівняння різних способів представлення тексту.

[Переглянути лабораторну роботу 1](Lab1/README.md)

### Лабораторна робота 2 — Word Embeddings

У роботі досліджено векторні представлення слів на основі попередньо навчених GloVe embeddings.

Основні теми:

- завантаження та використання GloVe-векторів;
- робота з `gensim.KeyedVectors`;
- аналіз векторів окремих слів;
- обчислення cosine similarity;
- пошук семантично схожих слів;
- порівняння власної реалізації з `gensim.most_similar`;
- векторизований пошук найближчих сусідів;
- візуалізація word embeddings;
- векторна арифметика;
- розв'язання аналогій на кшталт `paris - france + ukraine`.

[Переглянути лабораторну роботу 2](Lab2/README.md)

### Лабораторна робота 3 — Класифікація текстів за допомогою embeddings

У роботі попередньо навчені word embeddings використано для перетворення цілих документів у числові вектори та подальшої класифікації текстів.

Основні теми:

- токенізація тексту з урахуванням особливостей GloVe;
- метод Bag-of-Embeddings;
- побудова вектора документа шляхом усереднення векторів слів;
- векторизація навчальної та валідаційної вибірок;
- навчання логістичної регресії;
- порівняння Bag-of-Embeddings із TF-IDF;
- дослідження впливу розміру навчальної вибірки;
- структура embeddings matrix;
- отримання embedding через one-hot множення;
- використання `torch.nn.Embedding`.

[Переглянути лабораторну роботу 3](Lab3/README.md)

### Лабораторна робота 4 — Виправлення помилок у тексті

У роботі побудовано символьні мовні моделі для автоматичного виправлення помилок у текстах української поезії. Лабораторна виконана у форматі квесту з відновленням прихованого повідомлення.

Основні теми:

- символьна токенізація українського тексту;
- побудова словника з токенами `BOS` та `<unk>`;
- базова символьна 5-грамна модель зі згладжуванням;
- інтерпольована 7-грамна модель Єлінека—Мерсера;
- нейромережева Bengio Char-FFNN із контекстом попередніх символів;
- підготовка навчальних прикладів ковзним вікном;
- оцінювання кандидатів за negative log-likelihood;
- ансамбль статистичної та нейромережевої мовних моделей;
- автоматичний вибір виправлення помилкового слова;
- відновлення прихованого повідомлення;
- оцінювання моделей за accuracy та perplexity.

[Переглянути лабораторну роботу 4](Lab4/README.md)

### Лабораторна робота 5 — Генерація тексту

У роботі реалізовано процес генерації тексту за допомогою попередньо навченої авторегресійної моделі GPT-2.

Основні теми:

- завантаження GPT-2 через Hugging Face Transformers;
- токенізація та byte-pair encoding;
- робота з token IDs;
- отримання logits і ймовірностей наступного токена;
- softmax і log-probabilities;
- greedy decoding;
- випадковий sampling;
- temperature sampling;
- top-k sampling;
- nucleus sampling із параметром top-p;
- генерація тексту із заданого prompt;
- простий zero-shot експеримент;
- порівняння власної реалізації з `model.generate()`.

[Переглянути лабораторну роботу 5](Lab5/README.md)

### Лабораторна робота 6 — Декодування повідомлення рекурентною нейронною мережею

У роботі реалізовано forward-pass Elman RNN і жадібне декодування повідомлення, закодованого у наданих вагах мережі. Додатково реалізовано навчання RNN для кодування власного повідомлення та перевірку збережених параметрів.

Основні теми:

- структура Elman RNN;
- embedding символів;
- рекурентне оновлення прихованого стану;
- ReLU та вихідні logits;
- greedy decoding через `argmax`;
- робота з параметрами моделі, збереженими у JSON;
- узгодження форм матриць і транспонування ваг;
- порівняння NumPy- та PyTorch-реалізацій;
- навчання RNN на послідовності символів;
- cross-entropy loss та gradient clipping;
- збереження і повторне завантаження ваг;
- відновлення повідомлення з параметрів нейронної мережі.

[Переглянути лабораторну роботу 6](Lab6/README.md)

### Лабораторна робота 7 — Fine-tuning BERT для класифікації текстів

У роботі виконано донавчання моделі `ModernBERT-base` для бінарної класифікації тональності відгуків. Передбачення на тестовій вибірці використано для відновлення зображення у форматі квесту.

Основні теми:

- підготовка датасету у форматі Hugging Face Datasets;
- токенізація текстів за допомогою ModernBERT tokenizer;
- fine-tuning `ModernBertForSequenceClassification`;
- навчання через `transformers.Trainer`;
- оцінювання за accuracy, precision, recall і F1-score;
- візуалізація історії навчання та матриці помилок;
- класифікація текстів за допомогою `pipeline`;
- відновлення зображення з послідовності передбачень;
- порівняння з TF-IDF та логістичною регресією.

[Переглянути лабораторну роботу 7](Lab7/README.md)

### Лабораторна робота 8 — Генерація SQL із природної мови

Вебсервіс на Gradio, який перетворює текстовий запит українською на SQL-запит під задану схему бази даних і діалект СУБД за допомогою `gpt-4o-mini`.

Основні теми:

- text-to-SQL з урахуванням DDL-схеми;
- prompt engineering: системний промпт зі схемою, діалектом і жорсткими правилами формату виводу;
- детермінована генерація з `temperature = 0`;
- пост-обробка відповіді LLM (видалення markdown-огорож);
- підтримка PostgreSQL, T-SQL, MySQL і SQLite;
- демонстраційні схеми: магазин, бібліотека, університет, HR;
- складні випадки: `JOIN`, агрегація, віконні функції, рекурсивні CTE;
- обробка помилок API та робота з ключем через `.env`.

[Переглянути лабораторну роботу 8](Lab8/README.md)

### Лабораторна робота 9 — AI Examiner: LLM-агент для проведення іспиту

LLM-агент, який проводить усний іспит з NLP у чаті: ідентифікує студента, ставить питання по випадкових темах, оцінює відповіді та зберігає результат. Агентний цикл написано без фреймворків, на чистому function calling. Для тестування є AI-студент.

Основні теми:

- агентний цикл function calling без LangChain і подібних фреймворків;
- інструменти `start_exam`, `get_next_topic`, `record_topic_result`, `end_exam`;
- валідація аргументів і порядку викликів на боці коду;
- захист від prompt injection та маніпуляцій оцінкою;
- AI-студент із 7 персонами для автоматичного тестування екзаменатора;
- підтримка будь-якого OpenAI-сумісного провайдера (OpenAI, Gemini, Groq, OpenRouter, локальні моделі);
- чат-інтерфейс на Gradio з вкладкою результатів;
- збереження результатів і журналу подій у JSON / JSONL.

[Переглянути лабораторну роботу 9](Lab9/AI_Examinator/README.md)
