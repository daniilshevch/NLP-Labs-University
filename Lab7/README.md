# Лабораторна робота 7 — Fine-tuning BERT для класифікації текстів

Практична робота з донавчання попередньо навченої мовної моделі `ModernBERT-base` для бінарної класифікації тональності відгуків. Лабораторна виконана у форматі квесту: передбачення моделі на тестових текстах утворюють зображення, яке потрібно розпізнати.

## Мета

Навчитися готувати текстовий датасет для бібліотеки Transformers, токенізувати тексти, донавчати BERT-подібну модель для класифікації послідовностей та оцінювати якість отриманої моделі. Додатково виконано порівняння з класичним підходом на основі TF-IDF і логістичної регресії.

## Основне завдання

За допомогою `lpnlp` завантажено датасет відгуків із такими файлами:

- `train.txt` і `train.labels` — навчальні тексти та їхні класи;
- `valid.txt` і `valid.labels` — валідаційні тексти та класи;
- `test.txt` — тестові тексти без відомих міток;
- `metadata.json` — палітра для побудови зображення з передбачень.

Використано два класи:

| Значення | Клас |
|---:|---|
| `0` | `negative` |
| `1` | `positive` |

Тестова вибірка містить 9216 текстів. Кожне передбачення перетворюється на піксель: негативному відгуку відповідає чорний піксель, а позитивному — білий. Отримане зображення потрібно розпізнати.

## Реалізація

У `Lab7_NLP.ipynb` виконано такі етапи:

1. Завантажено датасет квесту через `lpnlp.start`.
2. Перемішано навчальні приклади з фіксованим `random_state=42`.
3. Сформовано `datasets.DatasetDict` із частинами `train`, `validation` і `test`.
4. Завантажено tokenizer моделі `answerdotai/ModernBERT-base`.
5. Виконано токенізацію з обрізанням послідовностей до 512 токенів.
6. Створено `ModernBertForSequenceClassification` із двома вихідними класами.
7. Реалізовано обчислення метрик accuracy, precision, recall і F1-score.
8. Донавчено модель за допомогою `transformers.Trainer`.
9. Побудовано графіки функції втрат, метрик і матриці помилок.
10. Виконано класифікацію тестових текстів через `pipeline`.
11. Перетворено послідовність передбачень на зображення та розпізнано закодований символ.
12. Навчено базову модель TF-IDF + Logistic Regression для порівняння.

## Параметри fine-tuning

| Параметр | Значення |
|---|---:|
| Модель | `answerdotai/ModernBERT-base` |
| Розмір навчальної вибірки | 10000 |
| Кількість класів | 2 |
| Batch size для навчання | 16 |
| Batch size для оцінювання | 32 |
| Кількість епох | 3 |
| Learning rate | `5e-5` |
| Weight decay | `0.01` |
| Максимальна довжина послідовності | 512 |
| Warmup | 10% від загальної кількості кроків |
| Точність обчислень | FP16 |

## Результати

### ModernBERT

На валідаційній вибірці отримано:

| Метрика | Значення |
|---|---:|
| Loss | `0.2122` |
| Accuracy | `0.9630` |
| Precision | `0.9546` |
| Recall | `0.9686` |
| F1-score | `0.9616` |

Під час навчання виконано 1875 кроків. Навчальна функція втрат після завершення тренування становила приблизно `0.1248`.

### TF-IDF + Logistic Regression

Для базового порівняння використано `TfidfVectorizer` із unigram та bigram ознаками і `LogisticRegression`.

| Метрика | Значення |
|---|---:|
| Розмір словника | 77176 |
| Accuracy | `0.8650` |
| Precision | `0.8688` |
| Recall | `0.8452` |
| F1-score | `0.8568` |

Fine-tuned ModernBERT продемонстрував вищу якість за всіма основними метриками.
