# Лабораторна робота 5 — Генерація тексту

Практична робота з використанням авторегресійної мовної моделі GPT-2 для генерації тексту.

## Мета

Розібрати принцип генерації тексту мовною моделлю: отримати розподіл імовірностей наступного токена, реалізувати різні стратегії декодування та генерувати текст із заданого prompt.

## Виконані етапи

- Завантажено попередньо навчену модель `GPT-2` через Hugging Face Transformers.
- Завантажено відповідний GPT-2 tokenizer.
- Досліджено токенізацію:
  - перетворення тексту на числові token IDs;
  - перетворення ID назад у токени;
  - розбиття рідкісних слів на підслова.
- Проаналізовано один крок роботи causal language model:
  - подано початковий `bos_token`;
  - отримано logits для словника;
  - перетворено logits на ймовірності через softmax;
  - розглянуто log-probabilities та числову стабільність.
- Реалізовано greedy decoding — вибір токена з найбільшою ймовірністю.
- Створено цикл генерації до появи `eos_token` або до досягнення `max_len`.
- Реалізовано BPE-декодування та перетворення послідовності токенів назад у звичайний текст.
- Узагальнено генератор через параметр `sample_fn`, щоб змінювати стратегію вибору наступного токена.
- Реалізовано та перевірено:
  - greedy choice;
  - простий випадковий sampling пропорційно ймовірностям;
  - sampling з temperature;
  - top-k sampling;
  - nucleus sampling (top-p).
- Додано генерацію тексту від заданого prompt, а не лише з початку речення.
- Проведено простий zero-shot експеримент: GPT-2 використано для продовження відгуків із позитивною та негативною тональністю.
- Порівняно власну реалізацію з готовим методом `model.generate()` у Transformers.
