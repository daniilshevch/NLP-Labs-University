# Лабораторна робота 2 — Word embeddings

Практична робота з векторними представленнями слів на основі попередньо навчених GloVe embeddings.

## Мета

Дослідити, як слова представляються в багатовимірному векторному просторі, навчитися вимірювати семантичну близькість слів і виконувати арифметичні операції над embeddings.

## Виконані етапи

- Підключено бібліотеку `gensim` для роботи з векторними моделями.
- Завантажено підмножину GloVe:
  - 50 000 найчастотніших слів;
  - розмірність кожного вектора — 200.
- Перевірено структуру `KeyedVectors` і доступ до вектора окремого слова.
- Проаналізовано вектор слова `ukraine`:
  - визначено його розмірність;
  - обчислено середнє значення компонент.
- Реалізовано власну функцію cosine similarity.
- Порівняно близькість слова `awesome` до:
  - `amazing`;
  - `great`;
  - `bad`.
- Реалізовано пошук найбільш схожих слів:
  - спочатку через послідовний перебір словника;
  - потім через векторизоване обчислення подібності для пришвидшення.
- Перевірено роботу пошуку для слів `awesome`, `awful`, `green` та інших прикладів.
- Порівняно власну реалізацію пошуку з методом `gensim.most_similar`.
- Досліджено цікаві та потенційно нелогічні сусідства слів у embeddings і пояснено, чому антоніми можуть мати близькі вектори.
- Підготовлено візуалізацію embeddings і найближчих сусідів за допомогою зниження розмірності.
- Продемонстровано векторну арифметику на прикладі:
  - `king - man + woman`;
  - `paris - france + ukraine`.
- Реалізовано пошук найближчих слів не лише для слова, а й для довільного результуючого вектора.
