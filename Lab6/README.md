# Лабораторна робота 6 — Декодування повідомлення рекурентною нейронною мережею

Практична робота з реалізації forward-pass Elman RNN та жадібного декодування повідомлення, закодованого у вагах рекурентної нейронної мережі. Додатково реалізовано навчання такої мережі для кодування власного повідомлення та перевірку збережених ваг.

## Мета

Зрозуміти, як рекурентна нейронна мережа зберігає послідовність у прихованому стані, навчитися вручну відтворювати її forward-pass за наданими параметрами та використовувати greedy decoding для відновлення прихованого тексту.

## Основне завдання

У каталозі роботи надано:

- словник символів `vocab.json`;
- embedding-матрицю `embedding.weight.json`;
- ваги переходу до прихованого стану `W_h.weight.json`;
- bias прихованого шару `W_h.bias.json`;
- рекурентні ваги `U_h.weight.json`;
- ваги вихідного шару `W_y.weight.json`.

Мережа має архітектуру Elman RNN із такими параметрами:

| Параметр | Значення |
|---|---:|
| Розмір словника | 133 |
| Розмір embedding | 48 |
| Розмір прихованого стану | 160 |
| Функція активації | ReLU |
| Початковий стан `h_0` | нульовий вектор |

Спеціальні символи словника:

- `[` — початок послідовності;
- `]` — кінець послідовності.

Для кожного кроку виконується така послідовність обчислень:

```text
x_t = embedding[message[t - 1]]
h_t = ReLU(W_h x_t + b_h + U_h h_(t-1))
y_t = W_y h_t
message[t] = vocab[argmax(y_t)]
```

Для першого кроку як поточний символ використовується `[`, а `h_0` ініціалізується нульовим вектором. Після обчислення `y_t` вибирається індекс найбільшого logit. Декодування завершується після отримання `]` або після досягнення обмеження кількості кроків.

### Узгодження форм матриць

Параметри з JSON можуть мати орієнтацію, відмінну від тієї, яка потрібна для матричного множення у формулах. У notebook перед декодуванням перевіряються такі випадки:

- `embedding`: `(48, 133)` транспонується до `(133, 48)`;
- `W_h`: `(48, 160)` транспонується до `(160, 48)`;
- `W_y`: `(160, 133)` транспонується до `(133, 160)`.

Після цього embedding для одного символу має форму `(48,)`, прихований стан — `(160,)`, а вихідний вектор logits — `(133,)`.

## Реалізація

У `Lab6_NLP.ipynb` виконано такі етапи:

1. Завантажено словник і всі параметри моделі з JSON.
2. Побудовано відображення `index_to_char` та `char_to_index`.
3. Перевірено й за потреби виправлено орієнтацію матриць транспонуванням.
4. Реалізовано цикл forward-pass на NumPy:
   - вибір embedding поточного символу;
   - обчислення нового прихованого стану;
   - обчислення вихідних logits;
   - вибір наступного символу через `argmax`.
5. Реалізовано той самий forward-pass у PyTorch із класом `RNN`.
6. Порівняно результати NumPy- та PyTorch-реалізацій.
7. Перевірено, що всі символи повідомлення представлені у словнику.

Softmax для greedy decoding не потрібен: він не змінює позицію максимального елемента, тому для вибору наступного символу достатньо безпосередньо застосувати `argmax` до logits.

## Додаткове завдання

У файлі [`Lab6Extra.py`](Lab6Extra.py) реалізовано зворотний експеримент: замість декодування готових параметрів мережа навчається відтворювати задане повідомлення.

Повідомлення за замовчуванням:

```text
за останні три роки я проїхав 180000 км на потягах укрзалізниці
```

Скрипт:

- створює `nn.Embedding`, прихований шар `W_h`, рекурентний шар `U_h` та вихідний шар `W_y`;
- формує навчальну послідовність із `[`, символів повідомлення та `]`;
- використовує попередні символи як входи, а наступні символи як targets;
- навчає модель за допомогою `Adam` і `CrossEntropyLoss`;
- застосовує gradient clipping із порогом `1.0`;
- кожні 50 епох виконує greedy decoding для контролю прогресу;
- зберігає параметри у JSON;
- завантажує збережені файли назад і перевіряє точне відтворення повідомлення.

Параметри навчання:

| Параметр | Значення |
|---|---:|
| Максимальна кількість епох | 5000 |
| Learning rate | `3e-3` |
| Gradient clipping | `1.0` |
| Seed | `42` |
| Точність збереження | 4 або 6 знаків після коми |
