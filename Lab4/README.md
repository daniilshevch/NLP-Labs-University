# Лабораторна робота 4 — Виправлення помилок у тексті

Практична робота з побудови символьної мовної моделі для автоматичного виправлення помилок у текстах української поезії. Лабораторна виконана у форматі квесту: правильне виправлення слів дає змогу відновити приховане повідомлення.

## Мета

Навчитися використовувати мовну модель для вибору найімовірнішого виправлення помилкового слова серед набору запропонованих кандидатів. Додатково дослідити оцінювання мовних моделей за допомогою negative log-likelihood і perplexity та порівняти статистичну, нейромережеву і гібридну моделі.

## Постановка задачі

Для навчання надається нерозмічений текст української поезії у `lab.train_text`. Тестові приклади містяться у `lab.test_items`. Кожен приклад має:

- повний текст із помилкою;
- позиції помилкового фрагмента `error_start` та `error_end`;
- слово з помилкою `error`;
- список можливих виправлень `corrections`.

Для кожного прикладу потрібно:

1. підставити кожен кандидат у початковий текст;
2. оцінити отриманий текст мовною моделлю;
3. вибрати кандидата з найменшим середнім negative log-likelihood;
4. порівняти вибране слово з помилковим і відновити одну літеру прихованого повідомлення.

Якщо слово не змінюється, до повідомлення додається пробіл. У результаті квесту приховане повідомлення містить рядок із вірша, а відповіддю є ім'я автора — **Сергій Жадан**.

## Виконані етапи

- Підключено пакет `lpnlp` і завантажено:
  - навчальний текст `lab.train_text`;
  - тестові елементи `lab.test_items`;
  - незалежний текст `lab.valid_text` для оцінювання perplexity.
- Реалізовано символьну токенізацію:
  - кожен символ є окремим токеном;
  - регістр, пробіли, переноси рядків і пунктуація збережені;
  - побудовано словник із 120 токенів;
  - додано службові токени `BOS` та `<unk>`.
- Реалізовано базову символьну 5-грамну модель зі згладжуванням Лапласа.
- Створено функцію для перевірки різниці між помилковим і виправленим словом та вилучення прихованої літери.
- Реалізовано оцінювання кандидатів за середнім negative log-likelihood.
- Реалізовано інтерпольовану символьну 7-грамну модель:
  - використано порядки від 1 до 7;
  - застосовано інтерполяцію Єлінека—Мерсера;
  - коефіцієнт інтерполяції `lambda = 0.65`;
  - для уніграмного рівня застосовано згладжування Лапласа з `alpha = 0.05`.
- Побудовано нейромережеву символьну мовну модель Bengio Char-FFNN:
  - контекст — 10 попередніх символів;
  - embedding-розмірність — 48;
  - два повнозв'язні приховані шари;
  - `LayerNorm`, `GELU` та `Dropout`;
  - оптимізатор `AdamW`;
  - функція втрат `CrossEntropyLoss`;
  - навчання протягом 15 епох.
- Підготовлено навчальні приклади ковзним символьним вікном.
- Побудовано ансамбль із 7-грамної та нейромережевої моделей:
  - вага 7-грамної моделі — `0.45`;
  - вага Bengio Char-LM — `0.55`;
  - фінальний score є зваженою сумою двох NLL.
- Під час навчання зберігалася найкраща версія нейромережевої моделі за accuracy на тестових прикладах.
- Збережено навчені ваги у файл `bengio_char_lm.pt`.
- Оцінено моделі на тексті `lab.valid_text`, який не використовувався для навчання.

## Результати

### Виправлення помилок

| Модель | Accuracy |
|---|---:|
| Базова 5-грама | 0.81 |
| Ансамбль під час навчання | до 0.85 |
| Фінальний ансамбль (найкраща епоха 15) | **0.85** |

### Perplexity на валідаційному тексті

Для всіх моделей використано один і той самий символьний токенізатор. Оскільки один символ відповідає одному токену, кількість токенів і символів однакова: `10 172`.

| Модель | Total NLL | Perplexity на токен | Perplexity на символ |
|---|---:|---:|---:|
| Bengio Char-FFNN | 18 557.22 | **6.1987** | **6.1987** |
| Інтерпольована 7-грама | 26 916.45 | 14.0994 | 14.0994 |
| Ансамбль | 19 154.24 | 6.5734 | 6.5734 |

Мінімальну perplexity на валідаційному тексті показала нейромережева модель. Ансамбль має трохи гірший результат за Bengio Char-FFNN на цьому тексті, але використовується для розв'язання квесту та досягає найкращої зафіксованої accuracy `0.85`.

## Запуск

Відкрийте notebook у Jupyter Notebook або Google Colab і виконайте комірки послідовно.

Під час першого запуску notebook:

1. встановлює пакет `lpnlp`;
2. запускає лабораторний квест через `lpnlp.start`;
3. завантажує навчальні, тестові та валідаційні дані;
4. навчає символьну нейромережеву модель;
5. оцінює кандидатів і відновлює приховане повідомлення;
6. обчислює perplexity для окремих моделей та ансамблю.

Для навчання можна використовувати CPU, однак доступний CUDA-пристрій автоматично використовується через `torch.cuda.is_available()`. Потрібен доступ до інтернету для встановлення `lpnlp` і роботи лабораторного сервісу.

У комірці запуску необхідно вказати власну електронну адресу:

```python
lab = lpnlp.start(
    email="your.email@example.com",
    lab="quest_spellchecker"
)
```

Значення `lab.valid_text` використовується лише для фінального оцінювання. Його не можна додавати до навчального корпусу або використовувати для побудови словника.
