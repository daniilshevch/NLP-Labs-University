# Лабораторна робота 4 — Символьна мовна модель і spellchecker

Практична робота з побудови мовної моделі на рівні символів і використання її для виправлення орфографічних помилок у тексті.

## Мета

Навчити модель прогнозувати наступний символ у тексті, а потім використати ймовірності мовної моделі для вибору найкращого виправлення слова з помилкою в контексті речення.

## Виконані етапи

- Підготовлено навчальні та тестові дані для задачі spellchecker.
- Побудовано символьний словник на основі навчального тексту.
- Додано спеціальні токени:
  - `BOS` для позначення початку послідовності;
  - `<unk>` для невідомих символів.
- Реалізовано символ-у-індекс та індекс-у-символ відображення.
- Побудовано статистичну символьну `n`-грамну мовну модель:
  - підрахунок частот символів після заданого контексту;
  - обчислення ймовірностей наступного символу;
  - використання згладжування Лапласа;
  - оцінювання тексту через середню від'ємну логарифмічну правдоподібність.
- Реалізовано функції для аналізу пар неправильне слово — правильне слово:
  - визначення символу, який було додано або видалено;
  - перевірка операцій виправлення на прикладах.
- Реалізовано пошук найкращого слова-кандидата за оцінкою мовної моделі.
- Реалізовано інтерпольовану `n`-грамну модель, яка поєднує статистику контекстів різної довжини.
- Реалізовано нейронну символьну мовну модель у PyTorch:
  - `nn.Embedding` для представлення символів;
  - feed-forward мережа;
  - фіксований контекст із 10 символів;
  - прогнозування наступного символу через класифікацію по словнику.
- Підготовлено навчальні вікна символів і `DataLoader`.
- Навчено нейронну модель за допомогою AdamW та `CrossEntropyLoss`.
- Реалізовано ансамблеве оцінювання кандидатів, що поєднує оцінки `n`-грамної та нейронної моделей.
- Проведено оцінювання spellchecker на тестових прикладах і вибір найкращих виправлень.
- Додано оцінювання мовної моделі на відкладеному тексті через perplexity:
  - perplexity на токен;
  - perplexity на символ.

## Запуск

Відкрийте notebook у Jupyter Notebook або Google Colab і виконайте комірки послідовно. Навчальні та тестові тексти надаються через навчальну платформу в об'єкті `lab`.

Під час запуску можуть знадобитися CUDA-сумісні ресурси для швидшого навчання нейронної моделі. Якщо GPU недоступний, модель автоматично використовує CPU.
