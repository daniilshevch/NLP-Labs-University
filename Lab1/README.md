# Лабораторна робота 1 — Класифікація текстів

Практична робота з побудови моделі бінарної класифікації текстів для визначення тональності відгуків на фільми.

## Мета

Реалізувати повний pipeline обробки тексту: від завантаження датасету та підготовки тексту до векторизації, навчання моделі й оцінювання якості. Модель визначає, чи є відгук позитивним або негативним.

## Виконані етапи

- Завантажено датасет **IMDB** через Hugging Face Datasets:
  - 25 000 прикладів для навчання;
  - 25 000 прикладів для тестування;
  - додатковий нерозмічений набір.
- Досліджено структуру датасету, тексти відгуків і числові мітки класів.
- Реалізовано токенізацію тексту двома способами:
  - за допомогою токенізатора spaCy;
  - за допомогою регулярних виразів.
- Реалізовано попередню обробку тексту:
  - приведення токенів до нижнього регістру;
  - стемінг алгоритмом Snowball/Porter;
  - видалення стоп-слів;
  - об'єднання кроків у функцію `preprocess`.
- Проаналізовано частотний розподіл токенів і скорочено словник:
  - відфільтровано рідкісні слова;
  - залишено найчастотніші токени;
  - додано спеціальний токен `<unk>` для невідомих слів.
- Створено клас `Vocabulary` з операціями:
  - token-to-index (`stoi`);
  - index-to-token (`itos`);
  - обробка токенів, відсутніх у словнику.
- Реалізовано способи представлення тексту:
  - one-hot кодування;
  - Bag-of-Words;
  - Bag-of-n-grams;
  - TF-IDF;
  - feature hashing.
- Побудовано ознаки для навчальної та валідаційної вибірок.
- Навчено логістичну регресію для класифікації тональності.
- Оцінено модель за метриками accuracy, precision, recall і F1-score.
- Порівняно різні налаштування `CountVectorizer`, розмір словника та діапазони n-грам.
